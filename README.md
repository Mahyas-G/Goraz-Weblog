A lightweight, robust weblog application built with Go, Echo, and PostgreSQL, utilizing a Server-Side Rendering (SSR) approach.

## Features

* **User Accounts:** Secure authentication and registration.
* **Blog Management:** Create, view, and delete posts (with optional image uploads).
* **Privacy Controls:** Public posts and private posts restricted to specific users.
* **Comments:** Interactive comment section for authenticated users.

## Tech Stack

* **Backend:** Go, Echo framework
* **Database:** PostgreSQL
* **Architecture:** MVC / Layered (Handlers, Services, Repositories)
